## Konkrete Empfehlungen (für „saubere“ AMD-Zahlen)

1. **Filter:** Alles mit `avg_power_w <= 0` bzw. `total_energy_j <= 0` ausschließen (RAPL nicht lesbar).
2. **RAPL-Zonen loggen:** Beim Start die **genaue PowerCap-Zone-Liste** (Namen) ins CSV schreiben (z. B. nur `package-0`). So erkennst du Doppelzählungen sofort.
3. **PPT fixieren:** Für reproduzierbare Vergleiche **PPT/TDC/EDC** im BIOS auf **Stock (TDP-nah)** setzen; Messung mit identischen Limits wiederholen.
4. **BLAS-Variante testen:** Gegenprobe mit **AOCL-BLIS** (AMD-optimiert). Ich erwarte bei großen N etwas höhere GFLOPS und ggf. bessere nJ/FLOP. ([AMD][5])
5. **Cross-Check Power:** Einmal extern (Steckdosen-Wattmeter) und, wenn möglich, **SoC/DRAM** separat prüfen, um 500 W-Ausreißer einzuordnen.
6. **Nur FP32 werten:** Dein Code nutzt **SGEMM** – Metriken/Peaks konsequent auf **FP32** beziehen.
