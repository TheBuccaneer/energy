# CONV2D platform analysis

Validates and analyzes the newest complete five-session CONV2D campaign for the enclosing platform.

```bash
cd <PLATFORM>/analyse/CONV2D
./run_all.sh
```

An explicit campaign may be selected with `--campaign YYYYMMDD_HHMMSS`.
Outputs are written to `<PLATFORM>/results/CONV2D/`. The scientific unit is the session median, not an individual technical repetition.
