# Installation

From the project root:

```bash
cd ~/projects/energy/new
unzip -o ~/Downloads/gemm_audit_handoff.zip
```

This adds:

- `AMD/results/GEMM/AUDIT_SUMMARY.md`
- `INTEL/results/GEMM/AUDIT_SUMMARY.md`
- `COMBINED/GEMM_COMBINED_AUDIT_DE.md`
- `COMBINED/GEMM_RESULTS_SUMMARY.md`
- `COMBINED/GEMM_HANDOFF_FOR_CLAUDE.md`
- `COMBINED/GEMM_KEY_RESULTS.csv`
- `COMBINED/GEMM_AUDIT_INDICATORS.csv`
