# REDUCTION pipeline audit design

The analysis is deliberately decision-centric:

- primitive axes: runtime and measured device-domain energy;
- joint axis: EDP;
- normalized inverse views: logical useful-data rate and logical GB/J;
- uncertainty unit: five independent session medians;
- tie-aware leaders: 2% practical equivalence plus interval overlap;
- exact-winner regret: descriptive post-selection supplement;
- no silent outlier removal;
- strict and 2% practical Pareto fronts;
- energy-boundary, internal-traffic and resident-GPU limitations are mandatory.
